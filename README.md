# hinex-client

Настройки клиента Hinex. Мод **HinexFeatures** читает `config.json` из этого репозитория при каждом запуске игры.

```
config.json      ← главный файл: правила, ресурспаки, сервера
packs/           ← zip-архивы ресурспаков (до ~50 МБ каждый)
.github/         ← автопроверка config.json на ошибки
```

> Репозиторий должен быть **публичным** — иначе игра не сможет скачать файлы.

## config.json

### Правила (TOS)

```json
"tos": {
  "url": "https://tos.hinex-server.ru/",
  "updated": "2026-09-26"
}
```

Изменили правила → поменяйте `updated` на сегодняшнюю дату. При следующем запуске игры каждый игрок
увидит окно «Правила обновлены» и должен будет принять их заново.

### Ресурспаки

```json
{
  "id": "hinex",
  "name": "Hinex",
  "url": "https://raw.githubusercontent.com/НИК/hinex-client/main/packs/hinex.zip",
  "mirrors": ["https://cdn.jsdelivr.net/gh/НИК/hinex-client@main/packs/hinex.zip"],
  "sha1": ""
}
```

| Поле      | Что это |
|-----------|---------|
| `id`      | Постоянное имя пака (латиница). **Не меняйте** после выпуска — по нему игра запоминает пак. |
| `name`    | Как пак называется в меню ресурспаков. |
| `url`     | Откуда качать. |
| `mirrors` | Запасные ссылки, если основная недоступна (необязательно). |
| `sha1`    | Необязательно. Если указать — мод проверит целостность файла. Пусто — мод сам узнаёт об изменениях по ETag. |

- Первый пак в списке — **самый приоритетный** (перекрывает остальные).
- Паки нельзя выключить или передвинуть в меню. Выше них могут быть только паки, которые присылает сам сервер.
- Мод скачивает пак один раз и дальше только проверяет, не изменился ли он.

Узнать SHA-1 файла (PowerShell):

```powershell
(Get-FileHash packs\hinex.zip -Algorithm SHA1).Hash.ToLower()
```

### Сервера

```json
"servers": [
  { "name": "HINEX | HUB", "ip": "hinex.joinserver.xyz", "style": "main" },
  { "separator": "Резервные сервера" },
  { "name": "HINEX | RESERV", "ip": "hinexreserv.joinserver.xyz", "style": "reserve" }
]
```

- `style: "main"` — яркая подсветка и значок HINEX, `"reserve"` — спокойная подсветка.
- `{ "separator": "текст" }` — полоса-разделитель с подписью.
- Сервера появляются вверху списка, их нельзя удалить, изменить или передвинуть.
  Если убрать сервер из конфига — он пропадёт и у игроков.

### Доверенные адреса

```json
"trustedHosts": ["hinex-server.ru"]
```

Данные клиента для досье (железо, моды) мод отправляет **только** серверам из `servers` и доменам из
`trustedHosts` (включая поддомены: `mc.hinex-server.ru`, `play.hinex-server.ru`…). Другим серверам —
ничего, кроме версии мода. Если появится новый адрес входа на Hinex — добавьте его сюда.

## Большие ресурспаки (> 50 МБ) — через Releases

GitHub не принимает в репозиторий файлы больше 100 МБ и предупреждает уже с 50 МБ. Для больших паков:

1. На странице репозитория: **Releases → Draft a new release**.
2. Tag: например `packs-1`. Перетащите zip в поле **Attach binaries** → **Publish release**.
3. Скопируйте ссылку на файл (ПКМ по файлу в релизе → «Копировать адрес ссылки»), она вида
   `https://github.com/НИК/hinex-client/releases/download/packs-1/hinex.zip`
4. Вставьте её в `url`. Зеркало jsDelivr для файлов из Releases не работает — `mirrors` оставьте пустым.
5. **Обязательно заполните `sha1`** — тогда мод не будет лишний раз обращаться к GitHub, пока хеш не изменится.

Чтобы обновить такой пак — загрузите файл с **тем же именем** в тот же релиз (старый удалите), либо сделайте новый релиз и поменяйте ссылку. В обоих случаях обновите `sha1`.

## Как долго доходят изменения

`raw.githubusercontent.com` кеширует файлы до **5 минут**, jsDelivr (зеркало) — до 12 часов.
Игроки получают изменения при следующем запуске игры.
