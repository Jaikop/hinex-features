# Ресурспаки

Кладите сюда `.zip` ресурспаков и прописывайте их в `config.json` → `resourcepacks`.

- В zip в корне должен лежать `pack.mcmeta` (не папка с паком внутри архива).
- Файл больше **50 МБ** лучше выкладывать не сюда, а в **Releases** репозитория (см. главный README).
- После замены zip ничего менять в `config.json` не нужно — мод сам заметит новую версию.
  Исключение: если заполнено поле `sha1`, его нужно обновить (или очистить).
